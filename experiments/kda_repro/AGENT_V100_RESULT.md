## 过程修复

原候选协议要求模型返回完整源码。两次独立请求分别在 12000 和 8000 completion tokens 达到
长度上限，服务返回空内容，未生成候选。控制器现改为精确局部替换协议，默认上限 4000 tokens；
首次响应只产生 757 个字符。空内容、结束原因和 token 用量会被记录，验证子进程也不再继承
模型 API 密钥。

并至少做三次独立重复，再决定该代数化简是否成为稳定基线。

这是本项目自编控制器对 KDA 思路的适配结果，不等同于 NVLabs 官方 Agent 工具链或 B200 竞赛成绩。
